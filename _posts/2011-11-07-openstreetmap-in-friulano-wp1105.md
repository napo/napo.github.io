<a href="http://www.mapefurlane.eu/"><img src="/assets/images/wordpress/2011/11/fvg-300x249.jpg" alt="" title="fvg" width="300" height="249" class="alignleft size-medium wp-image-1109" /></a>Grazie al lavoro di Andrea "<a href="http://www.openstreetmap.org/user/Klenje">Klenje</a>" Decorte ora è disponibile una mappa di OpenStreetMap della regione Friuli Venezia Giulia in friulano - <a href="http://www.mapefurlane.eu/">http://www.mapefurlane.eu/</a>

La mappa viene prodotta settimanalmente attraverso il software <a href="http://maperitive.net/">Maperitive</a> con questa configurazione - <a href="http://www.mapefurlane.eu/Furlan.mrules">http://www.mapefurlane.eu/Furlan.mrules</a>, sulla base delle estrazioni regionali in formato .osm che l'associazione <a href="http://gfoss.it/drupal/">GFOSS.it</a> mette disponibili all'indirizzo <a href="http://download.gfoss.it/osm/osm/">http://download.gfoss.it/osm/osm/</a>.
La libreria javascript scelta per la visualizzazione è <a href="http://leaflet.cloudmade.com/">leaflet</a>.

Un applauso ad Andrea per il lavoro svolto e, che altro dire, queste cose di certo non si possono fare con gmaps ;)
